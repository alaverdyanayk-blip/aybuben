# Проверки

Нужны Node.js и Playwright (`npm i playwright acorn`). Перед запуском: `python3 src/build.py` и в корне репозитория `python3 -m http.server 8765`.

- `node tools/qa/merge.js` — слияние прогресса (устройство + облако), сброс, старые схемы сохранения. Все строки должны начинаться с `OK`.
- `node tools/qa/translit.js` — сверяет «как звучит» у всех слов и фраз с побуквенным чтением и печатает расхождения.
  Расхождения — не ошибки, а места, где слово читается не по буквам (оглушение, связка եմ/եք/են, немая հ). Новое расхождение стоит перепроверить.
- `node tools/qa/dead.js` — имена верхнего уровня, которые нигде не используются.
