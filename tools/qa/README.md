# Проверки

**Перед каждой выкладкой:** `tools/qa/run.sh` — соберёт приложение, поднимет локальный сервер и прогонит все наборы. В конце «ВСЁ ПРОШЛО» или число непрошедших наборов; у каждого непрошедшего теста — что именно не так.

Нужны Python 3, Node.js 22+ и Playwright (`npm i playwright`, браузер — `npx playwright install chromium`).

## Наборы

- `app.test.js` — приложение в браузере. Отдельный тест можно запустить по части названия: `node tools/qa/app.test.js прописи`.
  - уроки: все проходятся подряд (+15 XP, сердца не тратятся), «Фразы», тренировка на разных этапах, сердца и экран «Сердца закончились», двойной запуск урока;
  - содержание: 40 прогонов генерации каждого урока — у каждого вопроса есть верный ответ, нет повторов, ответ собирается из плиток, у «послушайте» есть звук; повторения для каждой буквы и слова; данные букв и слов;
  - прописи на всех буквах: правильная обводка, обратный штрих, буква целиком одним движением, каракули, подсказка о числе штрихов;
  - прогресс: правила серии, 300 испорченных сохранений, починка цели и серии;
  - игры, звёзды «Фраз», карточка про канал, прогресс для напоминаний, 1500 случайных нажатий, вёрстка на 360 и 390 px.
- `tg.test.js` — режим Телеграма (Telegram WebApp и сервер подменены): вопрос про напоминания и «Да», гонка с медленным ответом сервера, второй вопрос при серии 3 дня, «выключил сам», кнопка под напоминанием `?r=…#go`, канал через `openTelegramLink`, облако Телеграма, метка приглашения, двойное касание на айфоне.
- `server-reminders.mjs` — сервер напоминаний без Cloudflare (база в памяти, в Телеграм ничего не уходит): кому, что и когда пишет бот, новички, шутки без повторов, новости с кнопкой, журнал и страница статистики.
- `merge.js` — слияние прогресса (устройство + облако), сброс, старые схемы сохранения. Все строки должны начинаться с `OK`.

## Вспомогательные

- `translit.js` — сверяет «как звучит» у всех слов и фраз с побуквенным чтением и печатает расхождения.
  Расхождения — не ошибки, а места, где слово читается не по буквам (оглушение, связка եմ/եք/են, немая հ). Новое расхождение стоит перепроверить.
- `dead.js` — имена верхнего уровня, которые нигде не используются (нужен `npm i acorn`).

## Как понять, что тест что-то ловит

Сломайте код нарочно и запустите нужный тест: например, верните `phStars(P)` вместо `phStars(P.id)` в `js/phrases.js` — тест «Фразы»: звёзды» должен упасть.
