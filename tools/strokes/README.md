# Прописи: откуда взялись штрихи

Формы букв сняты со шрифта **First Time Writing** (GGBotNet, лицензия CC0 — можно всё, без ограничений; страница: fonter.am/en/fonts/first-time-writing).

- `outlines.txt` — контуры букв из шрифта (упакованные точки).
- `sk.py` — чтение контуров и растр.
- `strokes.py` — осевые линии (скелет), разбор на штрихи, порядок и направление по общим правилам письма; ручные поправки к отдельным буквам — в `ov.json`.

Рабочий источник теперь — `src/data/strokes.js`: после генерации там правились отдельные буквы вручную (например, Օ/օ ведутся против часовой стрелки). Если перегенерировать, эти правки нужно повторить.

Проверить все буквы разом: каждая точная обводка должна засчитываться, обратная — ловиться как «в другую сторону» (тест `trall.js` в наборе проверок).
