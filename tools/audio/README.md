# Озвучка букв

`letters-audio.ps1` — скрипт для Windows (PowerShell). Запускается на компьютере владельца: ключ ElevenLabs вводится только в окне скрипта.
Список фраз зашит в скрипт (сгенерирован из `letters.json`): звук каждой буквы (гласная или слог «согласная + ա») и её армянское название.
Файлы называются так же, как остальная озвучка: fnv(ключ).mp3 — их нужно положить в `audio/` и добавить ключи в `src/data/audio-keys.js`.
Кнопки звука у буквы появляются сами, как только ключ есть в `AUDIO_KEYS`.
Название Յ озвучивается текстом «հի» (так оно звучит), а ключ остаётся «յի».
