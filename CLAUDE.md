# Айбубен — телеграм-бот @aybubenHAY_bot

Приложение для изучения восточноармянского (литературная норма), Duolingo-стиль, персонаж — абрикос Циро.
Сайт: https://alaverdyanayk-blip.github.io/aybuben/ (GitHub Pages, ветка main, корень). Бот открывает его как Mini App.
Артефакт-исходник на claude.ai: https://claude.ai/artifact/MLhXKy9k1YpundYV9zMX85

## Структура
Исходники раздельные, в бот уходит один собранный `index.html`.
- `src/app.html` — каркас страницы. `src/css/*.css` — оформление. `src/js/*.js` — логика и экраны. `src/data/*.js` — учебный контент.
- `src/build.py` склеивает всё в порядке списков `CSS` и `JS` (один `<style>` и один `<script>`, общая область видимости) и пишет:
  `index.html` + `version.json` (версия для Телеграма; руками не править) и `build/aybuben.html` (то же без Телеграма — для превью-артефакта, в git не хранится).
  Адаптер сверяет `version.json` и перезагружает Mini App, если Телеграм показал старую версию из кэша.
- Контент (`src/data/`): `letters.js` (буквы в порядке изучения, `L` — шаг), `words.js` (базовые слова), `themes.js` (13 тем, ~345 слов, [слово, как звучит, перевод]),
  `phrases.js` (9 ситуаций), `rules.js` (карточки правил `RC/RX/RN/RP/SIGNS`), `course.js` (разделы и уроки; id уроков менять нельзя), `ciro-lines.js` (реплики Циро),
  `outfits.js`, `achievements.js`, `audio-keys.js`. В начале каждого файла описан формат.
- Логика (`src/js/`): `state.js` (прогресс), `exercises.js`, `lesson.js`, `path.js` (главная), `games.js`, `reference.js` (буквы, словарь, правила), `phrases.js`, `profile.js`, `growth.js` (друзья, напоминания), `memory.js` (повторения), `sound.js`, `ciro.js`.
- Тема: `S.theme` (`light`/`dark`/`auto`), переключатель в профиле; `applyThemePref()` в `js/app.js`, в Телеграме — `__applyTheme` в адаптере. Облик — `src/css/tuf.css` (идёт последним, цвета только через переменные).
- Прогресс (`js/state.js`): один объект `S`, ключ localStorage `aybuben-v2`, поле `S.v` — версия схемы (`SCHEMA`). При изменении формата: поднять `SCHEMA` и добавить шаг в `MIGRATIONS` (только добавлять данные, ничего не удалять).
  С облаком Телеграма копии **сливаются** (`mergeState`): пройденное объединяется, числа по максимуму, настройки из более свежей копии; сброс помечается `resetAt`.
- `src/tg-adapter.js` — Telegram WebApp: тема, вибро, кнопка «Назад», CloudStorage (`syncFromCloud`), сброс (`__resetCloud`).
- Шрифты лежат в `fonts/` (Noto Sans/Serif Armenian, Golos Text, вариативные, OFL); `src/css/fonts.css` подключается только в версии для Телеграма, в превью — Google Fonts.
- `audio/*.mp3` — озвучка (ElevenLabs, eleven_v3). Имя файла = FNV-1a от ключа: текст без «։», trim, lowercase (см. `fnv`/`akey` в `js/sound.js`).
- `src/avatar.png`, `src/banner.png` — аватар бота и баннер Mini App.
- Раздел «Фразы» (`#phrases`, `#phrases/<id>`): уроки `phGen1`/`phGen2`, прогресс в `S.phr`. Костюмы `COSTUMES` открываются только за диалоги ситуаций; обычные `OUTFITS` — по уровню.
- Транскрипция: связка եմ/եք/են пишется «эм/экʰ/эн»; оглушение (աղջիկ — «ахчʰик»); հ после ր в շնորհակալություն, ճանապարհ, աշխարհ, խորհուրդ не пишется; ռ — «рр»; придыхательные — с «ʰ».
- Проверки: `tools/qa/` (слияние прогресса, сверка транскрипций, мёртвый код).

## Друзья и напоминания
- Приглашения: ссылка `t.me/aybubenHAY_bot?startapp=r<код>`; код выдаёт сервер (`/r/me`), друг засчитывается после первого урока (`/r/claim`, только новички ≤3 дней). Костюмы `REFC`: Гость (пришёл по ссылке), Семейный 1, Тамада 3, Ереванский дядя 5 друзей. В `S`: refBy, refClaimed, refCode, friends.
- Напоминания шлёт сам Worker (cron раз в час, `runReminders` → `plan`): не чаще раза в день, только если сегодня не занимался, в обычное время человека (или 19:00), тихие часы 23–9, «Реже» = раз в 3 дня, 3 игнора → раз в неделю, 6 → тишина. Тексты в `MSG` (worker.js), картинки `ciro/*.jpg` на Pages. Похвала — только в приложении (`ENDLINE`, `MILES`, `ciroStatus`).
- Первые три дня после знакомства (`notify.first`) вместо шутки — сообщения новичка: `MSG.new` (уже занимался: сколько букв знает и какой урок следующий) и `MSG.new0` (нажал «Старт», но не начал). Серия под угрозой важнее.
- Циро предлагает напоминания после первого урока и ещё один раз — когда серия дошла до 3 дней (`askNotif`, `S.notif.ask2`); кто выключил сам (`S.notif.off`), того не спрашивает.
- Замер: журнал `sent` (тип сообщения), кнопка под сообщением открывает приложение с `?r=<тип>` → событие `remind`; события `nt_ask/nt_yes/nt_no`. Блок «Напоминания за 30 дней» на странице статистики. Проверка: `node --no-warnings tools/qa/server-reminders.mjs`.
- Приложение шлёт `/u` (серия, день, часовой пояс, обычный час, краткий прогресс `info`: букв, уроков, следующий урок, сколько пора повторить); настройки (`notif`) — только когда человек сам их меняет, иначе сервер главнее (кнопки бота).
- Новости бота: `news.json` в корне (`[{"id":"уникальный","text":"…","mood":"cheer","until":"ГГГГ-ММ-ДД"}]`). После push cron сам разошлёт каждому, кто включил напоминания, один раз, в его обычный час, вместо напоминания того дня. В приложении разовая карточка «Что нового» (`whatsNew`, `NEWS_ID`).
- Нужен секрет BOT_TOKEN в Cloudflare (вводит пользователь); вебхук `/tg/<секрет>` ставится сам при первом запуске cron. Соль id больше не зависит от BOT_TOKEN.

## Статистика
- Страница: https://aybuben-stats.alaverdyanayk.workers.dev (пароль не задан — открыта по ссылке; можно добавить секрет ADMIN_PASSWORD).
- `server/worker.js` + `server/wrangler.toml` — Cloudflare Worker `aybuben-stats` + D1 `aybuben`. Cloudflare сам собирает его из GitHub при push (Workers Builds, Root directory = server).
- Приложение шлёт события через `src/stats-sender.js`; адрес сервера — в `src/analytics.json`, build.py вставляет отправщик. События: open, lesson, lesson_first, practice, fail, game (`track()` в приложении).
- Секреты (вводит только пользователь, в панели Cloudflare): ADMIN_PASSWORD, BOT_TOKEN (проверка подписи Telegram), SALT — все необязательны.

## Как выкатить обновление
1. Изменить файлы в `src/` (контент — в `src/data/`). Превью-артефакт публикуется из `build/aybuben.html` после сборки.
2. `python3 src/build.py`
3. `git add -A && git commit -m "…" && git push` — GitHub Pages обновится за ~1 минуту, бот подхватит сам.

Новые фразы для озвучки нужно сгенерировать (скрипт ElevenLabs запускается на компьютере пользователя, ключ вводит только пользователь) и положить в `audio/`, добавив ключи в `AUDIO_KEYS`.
